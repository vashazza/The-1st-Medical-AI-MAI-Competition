# The 1st Medical AI (MAI) Competition

**Korea University College of Medicine, Oct. 2024, Team Leader**

Medical image classification pipeline built for the 1st MAI Competition.

## Approach
- Built a ResNet50 baseline and a Swin Transformer classifier, and compared them under the same training setup.
- Set up hyperparameter configuration, augmentation, and validation for both models.

## Files
- `BaseLine Colab.ipynb`: Baseline training pipeline
- `Swin Transformer.ipynb`: Swin Transformer classifier
